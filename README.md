# Resume website

Local-only fictional commercial experience experiment. Do not publish or send as an actual employment history.

Run from this directory:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Open http://localhost:8080. The Save link downloads the PDF asset. EN uses SVG on desktop and HTML on mobile; RU uses HTML. Both languages use the same five sections.
